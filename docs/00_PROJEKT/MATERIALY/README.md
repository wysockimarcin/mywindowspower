# MATERIAŁY — pliki od użytkownika

Opcjonalny folder na materiały, które użytkownik chce przekazać Claude Code jako kontekst projektu (zrzuty ekranu wzorowego wyglądu GUI, własne skrypty, listy usług lub tweaków, wynik `$PSVersionTable` i `winver`).

Zasady:
- żadnych haseł, tokenów, kluczy ani danych prywatnych,
- każdy dodany plik wpisz do tabeli „Materiały od użytkownika" w `docs/00_PROJEKT/CONTEXT.md`,
- żaden plik nie jest wymagany do startu projektu.
